# Task 1.1: Tech Setup (`tech-setup`)

> **For agentic workers:** Use subagent-driven-development or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Initialize Next.js project, setup Supabase + Clerk, apply design system, deploy lên Vercel.

**Architecture:** Next.js App Router (Vercel) + Supabase (Postgres) + Clerk (Auth) + pnpm

**Tech Stack:** Next.js 16 · Supabase · Clerk · pnpm · Tailwind v4 · TypeScript

---

## Context & Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Auth | **Clerk** | UI components có sẵn, webhook tích hợp, free tier 10K MAUs |
| Database | **Supabase** (thay Neon) | Supabase đã có sẵn, Postgres mạnh |
| Git hosting | **GitHub** | Tích hợp Vercel CI/CD tốt nhất |
| Package manager | **pnpm** | Fast, disk efficient, ecosystem stable |
| DB access | **Supabase client trực tiếp** | Tận dụng Supabase features (RLS, realtime), gọn hơn Prisma |

### Notes
- Không dùng Prisma ORM → dùng Supabase client trực tiếp
- Supabase có free tier đủ cho MVP (500MB DB, 1GB storage, 2GB transfer/month)
- Clerk free tier: 10K MAUs, 10 webhook listeners

### Key Decisions & Deviations

- **Supabase factory pattern**: `createSupabaseAdmin()` gọi trong handler chứ không ở module scope → tránh build-time crash khi không có env vars
- **Clerk v7 middleware**: Dùng `async (auth, req)` + `await (auth() as any).protect()` vì `auth()` trả Promise
- **Không dùng Prisma**: Theo quyết định — Supabase client trực tiếp
- **svix**: Thêm package để verify Clerk webhook signatures
- **Step 3 (Vercel deploy)**: Chưa làm — cần credentials + GitHub repo
