# Task 1.2: Landing Page (`landing-page`)

> **For agentic workers:** Use subagent-driven-development or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Landing page đủ để thu email/user data từ ứng viên IT, chưa cần payment.

**Architecture:** Next.js App Router (Vercel) + ui-ux-pro-max + Tailwind v4

**Tech Stack:** Next.js 16 · pnpm · ui-ux-pro-max · TypeScript

---

## Context & Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Pricing Model | **Freemium + Lead Gen** | Build user base first → B2B revenue later |
| Monetization | **Lead Gen (B2B)** | Thu data ứng viên → bán cho recruiter/HR sau |
| User Value (Free) | **Full package free (limit 3 job)** | Tạo habit, thu data, conversion later |
| Signup Gate | **Required (signup để dùng)** | Thu email/name/tech skills = lead data |
| Lead Capture | **Signup = lead submission** | Không cần payment flow ở v1 |

### Notes
- **Per-job payment đã bỏ** → chuyển sang Freemium + Lead Gen
- Landing page không cần pricing section nữa
- Thay bằng: email signup → verify → full access
- **Trigger conversion B2B:** Sẽ define sau (recruiter outreach, candidate matching, job board)
